# Budsjettkalkulator

## Om prosjektet
Jeg har laget en nettside som hjelper brukeren med å holde oversikt over månedlig økonomi.

Brukeren kan legge til inntekter og utgifter, velge type og skrive inn beløp. Nettsiden regner automatisk ut totale inntekter, totale utgifter og saldo.

## Planlegging
Jeg startet med å lage grunnstrukturen i HTML. Deretter laget jeg designet med CSS. Etter det brukte jeg JavaScript for å få knappene og beregningen til å fungere.

## Valg jeg har tatt
Jeg valgte å ha inntekter og utgifter i hver sin boks for at siden skulle være enkel å bruke. Jeg la også til typer som lønn, stipend, mat og transport.

## Hvordan siden kjøres
Nettsiden kjøres ved å åpne `index.html` i nettleseren. Den kan også legges på en server for å gjøre siden tilgjengelig på nettet.
